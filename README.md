# 🛒 E-Commerce Website (PHP & MySQL)

This project is a full-featured e-commerce website built using **PHP**, **MySQL**, **HTML/CSS**, and **JavaScript**. It allows users to browse products, manage their shopping cart, place orders, and for admins to manage products, categories, and orders efficiently.

## 🚀 Features

### 🧑‍💻 User Functionality
- **User Registration & Login System**
- **Browse products by category**
- **Product details view**
- **Add to Cart & Remove from Cart**
- **Order placement and order history**
- **Responsive UI for mobile & desktop**

### 🛍️ Admin Panel
- **Add, edit, and delete products**
- **Manage categories**
- **Upload multiple product images**
- **Handle customer orders and statuses**

## 🧰 Technologies Used
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap
- **Backend**: PHP (Core PHP)
- **Database**: MySQL
- **Server**: Apache (XAMPP/WAMP)
- **Optional**: jQuery, FontAwesome
